# FloatingClock悬浮时钟

A floating clock based on QT, used to remind me that it's too late for "one more turn".

This LCD clock hovers above other windows and ignores any mouse click.

Position, size and color can be customized.

Setting window shows up on first startup, also can be summoned throuth system tary icon.

一个悬浮于画面顶层，位置, 尺寸和颜色可调整的LCD时钟。避免“再来一回合”结果天亮鸡叫的情况一次又一次发生。

设置窗口会在首次启动时显示，之后可以通过系统托盘调出。
